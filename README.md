# KidsSchool

Site familial style Duolingo : anglais, français et mathématiques (2e secondaire, Québec).
Sans compte ni base de données : tout reste sur l'appareil. L'élève voit son score ; les corrections sont dans l'Espace parents.

- Décisions : [docs/decisions.md](docs/decisions.md)
- Avancement : [docs/journal.md](docs/journal.md)
- Aide-mémoire des comptes : [docs/mes-comptes.md](docs/mes-comptes.md)
- Cahier des charges d'origine : [docs/cahier-des-charges.md](docs/cahier-des-charges.md)

Commandes : `npm run dev` (développement), `npm run build` (site dans `out/`), `npm run verifier` (contrôle des questions).
